# 密库（siyuan-edb）

把思源笔记中**选中的文档**及其**全部附件**（图片 / 视频 / 音频 / PDF / xlsx / docx / 任意格式），**实时**同步进一个 **加密的单文件数据库**（`.sydb`）。

理念：一份数据、一个文件、密码保护、本地优先、工作区零明文。

> `.sydb` 是本插件自研的加密 SQLite 容器格式（**MK 信封加密**：随机主密钥加密全部数据块与索引，密码只封装主密钥——改密码秒级完成；AES-256-GCM 逐块加密，无明文落盘）。
> 需要还原数据时，用面板的「导出 .md」或「恢复为思源文档」即可取回。

## 功能

- **选择性**：文档树右键 →「加入密库」/「移出密库」；也支持命令「把当前文档加入密库」
- **实时**：加入库的文档在编辑 / 新建 / 重命名 / 移动 / 删除后，自动（约 2.5 秒防抖）更新加密文件；启动时自动同步
- **加密**：AES-256-GCM + **Argon2id**（新库默认，OWASP 首选抗 GPU/ASIC 密钥派生，t=3/m=64MB）或 scrypt（旧库兼容）/ PBKDF2-SHA256（最旧库自动兼容），密码不落盘、无后门
- **🔑 恢复密钥（忘记密码可找回）**：新建库时可生成 12 个中文恢复词并落盘 `密库-恢复密钥.txt`；忘记密码时选「使用恢复密钥」解锁并重设新密码，数据完整找回——**不再锁死**
- **⚡ 改密码秒级完成**：MK 信封设计，改密码只重包装密钥区（O(1)），GB 级大库改密也瞬间完成；旧版本库首次解锁自动升级到新引擎
- **💡 弱密码检测**：纯数字 / 纯字母 / 常见弱密码（123456、password 等）建库时拦截提示
- **密码提示**：建库/修改密码时可填一句提示（存于库文件头部），解锁输错密码时自动显示帮你回忆
- **无密码模式**：创建库时密码留空即可——启动自动解锁，文件仍是完整加密字节
- **单文件**：正文 Markdown + 全部附件二进制，都在一个 `.sydb` 文件里，方便备份与移动
- **零明文**：打开文档时，图片以 data URL、视频/音频/PDF/xlsx 以 blob URL 直接从库内注入编辑器；大附件（>200MB）经本地流式服务播放——工作区磁盘上**不产生任何明文附件**；关闭文档后明文自动清除
- **可搜索**：标题 / 正文全文搜索；**🔍 OCR 图片文字搜索**：面板「🔍 OCR」按钮一键扫描库内图片，识别文字（简体中文+英文）加密存回库内索引，之后图片里的字也能搜到（识别模型走 CDN 首次联网加载，不占插件体积）；支持查看、复制全文、导出 .md、恢复为思源文档
- **大容量无上限**：索引区 + 追加数据区混合容器——解锁只读索引（几 MB），附件按 4MB 加密块追加存储、按偏移随机读，**库容量只受硬盘限制（TB 级）**
- **大附件流式播放**：超过 200MB 的视频/文件，打开时经本地流式服务按 Range 边播边解密（拖进度条也流畅），不整块载入内存、不落明文
- **文件夹整包入库**：整个文件夹自动打包 zip 加密进库
- **资产去重**：同内容文件（如重复保存的视频）自动复用数据块，**零新增写入**，库体积不膨胀
- **自动备份**：按间隔自动复制库文件到备份目录（MiKu-backup），保留多份
- **增量备份**：跨库/备份复用已存在数据块，备份飞快
- **深度自检**：解锁时自动抽查资产解密完整性；每周全量校验一次，损坏时提示用备份恢复
- **☁️ WebDAV 双向同步**：一键上传加密库到坚果云等 WebDAV 网盘（云端保留最新快照）；支持**从云端拉取**与定时自动拉取（多设备：本地留 conflict 副本不覆盖）
- **分库 / 归档**：一个文档一个库，或一个主题一个库，随意切换；封存旧库另开新库
- **智能分库（TF-IDF 语义自学习）**：自动按笔记本归属 + TF-IDF 内容指纹（向量余弦相似度）把文档分到最像的库，越用越准，可调相似度阈值（指纹仅存本地配置）
- **分库目录**：设置一个目录集中存放所有 `.sydb` 库文件，便于整体备份/迁移
- **库内回收站**：移出/删除的资产先进回收站（数据块保留），可逐条**恢复**或**彻底删除**，或**清空**；只有彻底删除/清空才释放空间；移出再加回同内容文件自动复用数据块、体积不翻倍
- **移出即还原**：移出密库时自动把该文档的图片/附件解密还原回思源 assets 目录
- **找回已移出资产**：设置 → 安全设置可扫描库内未被引用的加密数据块，解密还原到 assets 目录
- **🕘 版本历史（时间旅行）**：每次同步前自动留存文档快照（每文档 30 份 / 合计 5MB 上限），可查看、导出 .md、一键回滚到旧版本
- **📋 审计日志**：库内关键操作留痕（创建/解锁/恢复/改密/移出/升级等），可查看最近 200 条
- **📤 导出库副本**：一键复制当前加密库文件（随身携带 / 存档）
- **🛡 防误删确认**：移出密库前弹确认（说明还原行为与回收站去向）
- **⚠️ 敏感信息提醒**：文档出现身份证号 / 手机号 / 银行卡号时提醒加入密库保护（仅提示不存储）
- **📱 移动端读写（6 位访问码）**：手机/平板浏览器访问（同一 WiFi）可浏览全部文档；输入电脑端面板显示的「移动访问码」（10 分钟有效）即进入编辑模式——可**编辑、新建、删除文档，上传照片/视频**，全部加密写入库内，密码不经过局域网
- **🔐 TOTP 双因素解锁（行业新技术）**：设置 → 安全设置可开启双因素——生成密钥录入任意验证器 App（Google Authenticator 等），开启后解锁需「密码 + 6 位动态码」双校验，密码泄露也打不开库
- **🛡 防勒索/防篡改监控（行业新技术）**：后台定时（默认 60 分钟）采样校验库文件完整性，库文件被外部修改/替换（勒索加密、杀软误操作、手动篡改）立即告警并记入审计日志；插件自身写入自动跳过误报
- **🔥 阅后即焚分享**：文档树右键库内文档生成一次性分享链接（24 小时内打开一次即销毁），临时给家人/朋友看一份资料不留痕
- **⏳ 到期倒计时 + 自动更新检查**：面板授权区显示「剩余 N 天 / 今天到期 / 已到期 N 天」；设置填更新清单 URL 后启动自动检查，发现新版本弹窗提示

## 使用

1. 安装插件后在 **设置 → 密库设置** 里确认数据库文件路径（默认在思源工作区 `data\MiKu\密库.sydb`，可改成任意路径，如 `E:\私库.sydb`）
2. 文档树右键任意文档 → **加入密库** → 按提示设置密码（首次会创建加密库文件；留空 = 无密码模式）
3. 之后编辑该文档，插件会自动把最新内容加密写入 `.sydb`
4. 顶栏 🍯 图标 / 命令「打开密库面板」可查看：文档数、大小、最近同步、搜索、导出、恢复、回收站

## 数据说明

- 同步内容为文档的 **Markdown 全文 + 全部附件二进制**（图片/视频/PDF/xlsx 等），都在加密库内
- 加密库文件位置可随时改：设置里修改路径即可（改后自动迁移写入）
- 修改密码：面板 →「修改密码」（需先解锁；可顺带补填密码提示）
- 解锁状态只保存在内存中，关闭思源后需要重新输入密码（无密码模式自动解锁）
- 移出密库：资产自动还原回思源 assets 目录，且库内条目进入回收站（可恢复）

## 常见问题

- **忘记密码**：建库时生成过恢复密钥的话，解锁失败 →「使用恢复密钥」输入 12 个恢复词即可解锁并重设新密码；没有恢复密钥则无法恢复（加密无后门），请务必牢记密码；解锁失败时若填过密码提示会自动显示
- **忘记 TOTP 动态码 / 验证器丢了**：双因素开启前请先在设置页把「密钥」抄写保存一份；验证器丢失时暂无法解锁（密码+TOTP 双校验），可联系卖家协助处理
- **激活码换电脑**：激活码与设备绑定（一码一机）。换机时联系卖家（微信 nglzhy）解绑后重新绑定新机器
- **想还原数据**：面板搜索 → 点文档 →「恢复为思源文档」（创建回原笔记本），或「导出 .md」拿到独立文件
- **删除文档后**：库内对应记录自动移入回收站（可恢复或彻底删除）
- **库文件越来越大**：解锁后面板会提示「♻ 可回收空间约 X」，到 设置 → 安全设置 →「立即压缩回收空间」即可释放
- **多设备**：在 WebDAV 设置里配置同一网盘，A 设备「推送」，B 设备「从云端拉取」（或开启定时自动拉取），即可在两台电脑间同步加密库

## 授权激活（付费版）

本插件为**付费授权**使用，安装后需要激活码才能启用实时同步与零明文功能。

- 打开**设置 → 密库设置 → 🔑 授权激活**，粘贴 **激活码 + 绑定码**（双码）→ 点「激活」
- **激活码**由卖家签发（ed25519 签名、无法伪造），按时长分为：**月 9.9 元 / 半年 29.9 元 / 年 49.9 元 / 永久 99 元**，从激活当日开始计时（永久码不过期）；再次购买新码激活会在原到期日**自动叠加天数**
- **绑定码**：把插件设置页显示的**本机设备指纹**发给卖家，换取对应绑定码——激活码只能绑定这一台电脑（**防一码多用**），换机需联系卖家解绑
- **到期前 7 天**启动时提醒续费；到期后文档仍可正常查看，插件暂停自动同步与零明文清理
- **购买激活码请联系微信：nglzhy**（转账后发码）
- 新安装未激活时自动进入 **7 天试用**（面板显示剩余天数）
- 激活状态保存在本机 `data/storage/petal/siyuan-edb/license.json`

> 说明：本插件为离线授权方案，不联网验证。已内置**防时钟回拨**：系统时间被回拨超过 5 分钟会被检测并冻结试用/授权。

## 兼容性

- 桌面端思源 v3.0.0+（含 Windows / macOS / Linux 主窗口）
- 移动端：官方不加载第三方插件，但可用内置**只读查看器**在手机/平板浏览器查看

## 隐私

- 数据全部本地加密存储，不上传任何明文；WebDAV 上传的也是加密库文件
- 智能分库指纹仅存本地配置（词频统计，不存原文）
- 密码不落盘、不联网
