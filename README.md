# 密库 · Secret Database

<div align="center">

<img src="logo.png" width="320" alt="密库 Logo" />

**密库 · Secret Database**

**思源笔记的「本地数据保险箱」**

</div>

> **一句话主张：** 一份数据、一个文件、密码保护、本地优先、工作区零明文、**任何工具都无法查看未经过你同意授权的数据**。

密库（Secret Database）不是又一个"云同步笔记"，而是一套**跑在你自己电脑上的加密库**：文档、图片、视频等任意格式资料加密后收拢进单个 `.sydb` 文件。只有输入正确密码时才在内存里解密显示，磁盘上不留任何明文；不开库，任何软件、任何工具都读不到内容。

---

## 六大理念

| 理念 | 介绍 |
|---|---|
| **一份数据** | 你的资料只有一份，入库即是正本，不再有明文副本散落各处。 |
| **一个文件** | 所有资料收进一个文件，换机、备份、拷贝，带它一个就够了。 |
| **密码保护** | 密码即钥匙：正确密码才能开锁，没有密码，文件再多人也读不懂。 |
| **本地优先** | 数据永远在你自己手里，不上云、不联网也能开库、看库。 |
| **工作区零明文** | 工作区里看不到任何明文：打开是解密给你看的，关上硬盘里只剩密文。 |
| **未授权不可见** | 没经过你的同意授权，任何工具都打不开它——这就是密库存在的意义。 |

## 它能做什么

- **整本笔记本入库**：文档树右键笔记本 →「整本加入密库」，递归加密全部文档，明文附件自动清理；「整本移出密库」一键还原
- **单文档入库**：文档树右键 →「加入密库」/「移出密库」，实时自动同步
- **任意格式全支持**：图片 / 视频 / 动态图（GIF）/ 音频 / PDF / xlsx / docx 及任何格式附件，全部加密进库
- **实时加密**：入库文档编辑 / 新建 / 重命名 / 移动后，自动把最新内容加密写入 `.sydb`
- **移出即还原**：移出密库时，文档附件自动解密还原回思源 assets 目录
- **自动备份**：按间隔自动复制加密库到备份目录，保留多份；增量备份复用数据块，飞快完成

## 适合谁

在思源笔记里存放**敏感资料**的用户——私人笔记、凭证、影像素材：既想要思源流畅的编辑体验，又不想让明文数据裸躺在工作区里。

## 快速上手

1. 安装插件后，在 **设置 → 密库设置** 确认数据库文件路径（默认 `data\MiKu\密库.sydb`，可改成任意路径）
2. 文档树右键任意文档或笔记本 → **加入密库** → 按提示设置密码（留空 = 无密码模式）
3. 之后编辑文档，插件自动把最新内容加密写入 `.sydb`；顶栏图标 / 命令「打开密库面板」查看状态与操作

新安装未激活自动进入 **7 天试用**。

## 功能速览

- **强加密**：AES-256-GCM 逐块加密 + **Argon2id**（新库默认，OWASP 首选抗 GPU/ASIC KDF），兼容旧库加密方案；密码不落盘、无后门
- **🔑 恢复密钥**：建库时生成 12 个中文恢复词，忘记密码可找回并重设——不再锁死
- **⚡ 改密码秒级完成**：信封式密钥设计，GB 级大库改密瞬间完成
- **无密码模式**：创建库时密码留空——启动自动解锁，文件仍是完整加密字节
- **可搜索**：标题 / 正文全文搜索；**🔍 OCR 图片文字搜索**（简体中文+英文，识别模型走 CDN 不占体积）
- **大容量无上限**：数据按加密数据块存储、按需读取，**库容量只受硬盘限制（TB 级）**
- **大附件流式播放**：超过 200MB 的视频/文件经本地流式服务按 Range 边播边解密，不整块载入内存、不落明文
- **文件夹整包入库**：整个文件夹自动打包 zip 加密进库
- **资产去重**：同内容文件自动复用数据块，零新增写入，库体积不膨胀
- **☁️ WebDAV 双向同步**：一键上传加密库到坚果云等网盘，支持从云端拉取（多设备）
- **分库 / 智能分库**：一个文档一库 / 一个主题一库；TF-IDF 语义自学习自动把文档分到最像的库
- **库内回收站**：移出/删除的资产先进回收站（数据块保留），可恢复或彻底删除
- **🕘 版本历史**：每次同步前自动留存快照，可查看、导出、一键回滚
- **📋 审计日志**：库内关键操作留痕（最近 200 条）
- **📱 移动端读写**：手机/平板浏览器（同一 WiFi）浏览全部文档，输入 6 位访问码可编辑、上传
- **🔐 TOTP 双因素解锁**：密码 + 6 位动态码双校验，密码泄露也打不开库
- **🛡 防勒索/防篡改监控**：后台定时采样校验库文件完整性，被外部修改立即告警
- **🔥 阅后即焚分享**：生成一次性分享链接（24 小时内打开一次即销毁）
- **⚠️ 敏感信息提醒**：文档出现身份证号/手机号/银行卡号时提醒加入密库保护（仅提示不存储）

## 常见问题

- **忘记密码**：有恢复密钥 →「使用恢复密钥」输入 12 个恢复词即可解锁并重设新密码；没有则无法恢复（加密无后门），请务必牢记密码
- **激活码换电脑**：激活码与设备绑定（一码一机），换机联系卖家（微信 nglzhy）解绑后重新绑定
- **想还原数据**：面板搜索 → 点文档 →「恢复为思源文档」或「导出 .md」
- **库文件越来越大**：解锁后面板提示「♻ 可回收空间约 X」，到 设置 → 安全设置 →「立即压缩回收空间」即可释放
- **多设备**：WebDAV 设置里配置同一网盘，A 设备「推送」、B 设备「从云端拉取」即可同步

## 授权激活（付费版）

本插件为**付费授权**使用，安装后需要激活码才能启用实时同步与零明文功能。

- **设置 → 密库设置 → 🔑 授权激活**，粘贴 **激活码 + 绑定码** → 点「激活」
- **激活码**由卖家签发、无法伪造：**月 9.9 元 / 半年 29.9 元 / 年 49.9 元 / 永久 99 元**，从激活当日计时；再次购买自动叠加天数
- **绑定码**：把插件设置页显示的**本机设备指纹**发给卖家换取——激活码只能绑定这一台电脑（防一码多用）
- **购买激活码请联系微信：nglzhy**（转账后发码）
- **📮 问题反馈**：使用过程中遇到问题（包含截图），可以直接联系微信反馈，我们会根据事实修复

## 兼容性

- 桌面端思源 v3.0.0+（Windows / macOS / Linux）
- 移动端：官方不加载第三方插件，可用内置**只读查看器**在手机/平板浏览器查看

## 隐私

- 数据全部本地加密存储，不上传任何明文；WebDAV 上传的也是加密库文件
- 智能分库指纹仅存本地配置（词频统计，不存原文）
- 密码不落盘、不联网

> `.sydb` 是本插件自研的加密容器格式：**强加密逐块保护全部数据与索引，密码只用于解锁，无明文落盘**。需要还原数据时，用面板的「导出 .md」或「恢复为思源文档」即可取回。
