## 先说一件你可能没想过的事

你电脑里的思源笔记，**现在是完全敞开的**。

不是"有点不安全"，是**完全敞开**——任何一个能碰到这台电脑的人，打开文件夹就能读到你写的每一个字、存的每一张图、每一段视频：

| 那个"能碰到电脑的人" | 他会看到什么 |
|---|---|
| **借电脑的朋友/亲戚** | 你随手记的心事、体检报告、私密日记 |
| **来家里修电脑的师傅** | 你所有资料，包括你压根没打算给任何人看的 |
| **公司 IT / 同事** | 你电脑上的一切（很多人电脑是公司发的） |
| **看你屏幕的人** | 你正在写的每一行字（开会投屏、旁边工位、地铁上） |
| **捡到你旧电脑的人** | 硬盘拆下来就能读，密码锁屏根本挡不住 |
| **你自己不小心** | 截图、录屏、微信发错人、云备份同步到不该去的地方 |

**你存的越私密，敞开的代价越大。**

## 密库解决的，不是"加密技术问题"，是"你会不会出事"

我们不跟你讲算法。只说一句人话：

> **把东西放进密库，就等于把它锁进了只有你有钥匙的保险箱。**
> 别人拿到你的电脑、拆走你的硬盘、借你的电脑、看你屏幕——
> **没有你的密码，他们一个字都看不到。**

## 你会因为什么买了它，并且再也不后悔

### 🚨 有人借你电脑，"我就用一下"
- **没有密库**：你手心冒汗，一直盯着他鼠标。
- **有密库**：你根本不用管。密库里的东西在文档树里**根本不显示**。

### 🚨 电脑要送修 / 要卖掉 / 要借给家人
- **没有密库**：要么把文件删了（修完没了），要么赌对方不看。
- **有密库**：数据加密在**一个文件**里，锁着就是一堆乱码。拔了硬盘也读不出。

### 🚨 屏幕被人看到的那 0.5 秒
- **没有密库**：来不及切窗口，内容已经露了。
- **有密库**：没解锁时正文是**糊掉的**，只显示"密库已锁定"。

### 🚨 那些"存了但不敢让人知道"的资料
体检报告、病历、私聊备份、私人影像、身份证扫描件、合同、账目……
**共同点：你确实需要留着，但绝不能被人看到。**
存网盘？上传即失控。存文件夹？等于没锁。删掉？你又需要它。

> **密库就是为"必须留着、又绝不能被人看到"这类东西造的。**

### 🚨 你以为"设了开机密码就安全了"
**不是。** 开机密码只挡"坐到电脑前的人"。硬盘拆下来、PE 启动盘一插、或者有人拿到你的备份——**开机密码一秒失效**。

## 为什么不用别的办法？

| 你的替代方案 | 实际结果 |
|---|---|
| **存普通文件夹** | 等于没锁，任何人打开就看见 |
| **存网盘 / 云笔记** | 上传那一刻就失控了。平台能看到、能被泄露 |
| **系统加密软件（BitLocker/VeraCrypt）** | 整盘加密：一开电脑全解锁，**挡不住"借电脑的人"**；且和思源割裂 |
| **压缩包加密码** | 每次看都要解压；**密码还能被暴力破解**，文件名也藏不住 |
| **思源自带加密笔记本** | 方向对，但**只能随工作区走**；不能单文件带走、不能手机看、不能单篇分享 |
| **密库** | **边写边加密**、**一个文件带走**、**手机上也能看**、**别人碰不到** |

## 常见问题

**Q：免费版有什么限制？**
免费版**永久可用**，支持加密/锁定/遮罩/恢复密钥/自动同步/备份，上限 **10 篇文档、1 个密库**。网盘同步、手机查看、阅后即焚、双因素等进阶功能需付费。

**Q：试用到期后我的数据会怎样？**
**不会有任何影响。** 数据仍然加密、仍然能正常打开。只是从"全功能"变成"免费版"，超出免费额度的部分仍可正常查看和移出。

**Q：忘记密码怎么办？**
建库时自动生成的**恢复密钥**（12 个中文词）可以解锁并重设密码。**请抄在纸上**，不要和库文件放一起。没有恢复密钥则无法恢复——这是"无后门"的代价。

**Q：换电脑了怎么用？**
把 `.sydb` 文件拷到新电脑，用密码解锁即可。授权免费重绑（每年 3 次），联系微信 nglzhy。

**Q：想还原成普通思源文档？**
面板搜索 → 点文档 →「恢复为思源文档」或「导出 .md」。

**Q：库越来越大？**
解锁后面板会提示「♻ 可回收空间约 X」，到 设置 → 安全设置 →「立即压缩回收空间」。

**Q：和思源自带的加密笔记本有什么区别？**
思源自带加密是"整本笔记本 + 只能随工作区走"。密库是**一个文件带走**、**能手机看**、**能单篇分享**、**能网盘增量同步**、**附件单独加密**。两者不冲突，可以一起用。
